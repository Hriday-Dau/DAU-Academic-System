📋 Required CSV Format Specifications:

The uploaded CSV must have a header line with the following column headers:

stdinstid,stdfirstname,stdmiddlename,stdlastname,stdemail,stdgender,stddob
  • stdinstid: Unique Institute ID (e.g. 202401001)
  • stdfirstname & stdlastname: Student names (required)
  • stdmiddlename: Middle name (optional, leave empty if not applicable)
  • stdemail: Student email address (unique)
  • stdgender: M, F, or O
  • stddob: Date of birth (format: YYYY-MM-DD or DD-MM-YYYY)
  • Accounts: User accounts are created automatically with role Student (914) and default password Daiict@26.
